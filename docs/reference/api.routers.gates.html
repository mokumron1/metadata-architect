CI/CD gate endpoints: Context-First (Gate 1) and Jargon Scrubber (Gate 2).

Overview

CI/CD Gate endpoints. Gate 1 — Context-First: rejects pipeline assets that have no registered Statement of Intent. Blocks deployment until metadata is authored and approved. Gate 2 — Jargon Scrubber: runs the JargonScrubber agent against a supplied SoI text. Returns the violation list so CI/CD pipelines can fail on non-compliant prose. Both endpoints require the X-Gate-API-Key header to authenticate the calling CI/CD system.
