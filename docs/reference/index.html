API Reference

Project: Metadata Architect AI Agent Version: 0.1.0 Generated: 2026-06-02
Complete reference documentation for all Python modules in the Metadata Architect AI Agent. The system eliminates the "Translation Tax" by auto-drafting 80% of data asset metadata, leaving SMEs as Context Editors rather than Data Janitors.
